# Real Estate Analytics and Prediction

## Project Overview

This project analyzes real-estate property data and provides machine learning-based predictions through an interactive Streamlit dashboard.

The application performs exploratory data analysis, future property price prediction, and good investment classification.

## Project Features

- Data cleaning and preprocessing
- Feature engineering
- 20 EDA questions and visualizations
- Future property price prediction
- Good investment prediction
- Interactive Streamlit dashboard
- Regression and classification model comparison

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Streamlit
- Joblib

## Machine Learning Models

### Regression Models

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- XGBoost Regressor

### Classification Models

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Gradient Boosting Classifier
- XGBoost Classifier
